# Valuable Skills

## [Superpowers](https://github.com/obra/superpowers)

An agentic framework that equips coding agents with a comprehensive software development workflow through composable "skills." Automatically activates for tasks like design, planning, testing, and code review — orchestrating agents through stages including design refinement, git-based isolation, test-driven implementation, and autonomous task execution with built-in quality checkpoints.

## [Frontend Design Skill](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md)

A Claude Code skill for creating distinctive, production-grade frontend interfaces that avoid generic AI aesthetics. Guides the agent to commit to a bold design direction with meticulous attention to typography, color, motion, and spatial composition — generating real working code (HTML/CSS/JS, React, Vue, etc.) that is visually striking and cohesive.
